# VERCETI для Windows

Окремий настільний клієнт VERCETI на Electron. Він відкриває повну вебверсію в окремому вікні застосунку, тому використовує ті самі акаунти, права доступу, базу даних Supabase та актуальні функції сайту. Інтерфейс і функціонал не дублюються в окремій кодовій базі — оновлення вебзастосунку автоматично доступні й у лаунчері.

## Вимоги

- Windows 10 або Windows 11, x64.
- Підключення до інтернету.
- Node.js LTS лише для локального запуску та складання інсталятора.

## Запуск у режимі розробки

У цій папці:

```powershell
npm install
npm run desktop
```

## Створення інсталятора

```powershell
npm install
npm run dist:win
```

Готовий інсталятор з'явиться в папці `release` як `VERCETI-Setup-1.0.0.exe`.

## Можливості оболонки

- Окреме вікно VERCETI з власною назвою застосунку.
- Збереження сесії входу між запусками.
- Доступ до мікрофона для голосових кімнат після дозволу користувача.
- Зовнішні посилання відкриваються у браузері, а не підміняють вікно застосунку.
- Клавіші F5 / Ctrl+R для оновлення, Ctrl+0 для масштабу, Ctrl +/- для зміни масштабу.
- Екран повторного підключення, якщо немає інтернету.

## Важливо

Лаунчер наразі є онлайн-клієнтом: для входу, чатів, голосових кімнат, новин та інших функцій потрібен інтернет. Він не створює окрему базу користувачів і не змінює вебзастосунок або мобільний застосунок.
